1. `start()` - The executor service is created as an instance field but never stored in a way that allows proper shutdown beyond `shutdownNow()` in `stop()`, risking thread leaks if exceptions occur before `@PreDestroy` runs.
2. `stop()` - Calling `heartbeat.shutdownNow()` followed by `metrics.removeListener(this::forward)` creates a race condition where the listener may still be invoked after removal since scheduled tasks could execute concurrently with shutdown.
3. `stop()` - Iterating over `emitters` while calling `emitter.complete()` does not prevent concurrent additions to the list from other threads during cleanup, potentially causing `ConcurrentModificationException`.
4. `MetricsStreamController(InMemoryTelemetryMetrics metrics)` - The constructor accepts a mutable dependency without defensive copying or null checking, allowing callers to pass null or modify the reference post-construction.
5. `start()` - Registering the listener via `metrics.addListener(this::forward)` happens before the heartbeat scheduler starts, creating a window where forwarded events have no active emitter connections yet.
6. `stop()` - After clearing emitters and shutting down the heartbeat, any pending scheduled beats will throw NPE when attempting to forward to an empty list, though this is minor compared to the race conditions above.
7. `JsonMapper json = JsonMapper.builder().build()` - Creating a new ObjectMapper instance per controller instead of reusing a shared singleton wastes resources and prevents consistent configuration across instances.
