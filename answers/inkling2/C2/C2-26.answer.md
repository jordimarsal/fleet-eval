1. Settings.model_config `env_file=".env"` — relative path makes config depend on process CWD and can load an unintended `.env` from the current directory instead of a stable project root.
2. Settings.model_config `extra="ignore"` — misspelled or stale `CODERAG_*` variables are silently discarded, so typos become surprising default-value behavior rather than validation errors.
3. Settings `repo` — relative `"."` resolves against whatever working directory invokes the app, breaking repo discovery when launched elsewhere.
4. Settings `chunk_size` — plain `int` accepts zero/negative values (e.g. via env) that would cause empty chunks or invalid splitting later instead of failing at startup.
5. Settings `embedder_backend` / `retrieval_strategy` / `bm25_backend` — free-form strings accept unknown backend names, deferring dispatch failures to runtime instead of validating supported options at load time.
6. Settings `database_dsn` — unvalidated string accepts malformed DSNs and downstream driver/connection assumptions only fail after settings load; no format/scheme check is performed.
7. Settings `embedder_url` — arbitrary URL with no scheme/host restriction permits cleartext HTTP to remote embedders while still looking well-configured locally, risking content sent over unencrypted channels.
