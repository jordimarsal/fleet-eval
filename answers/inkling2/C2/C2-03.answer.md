1. `max_turns` is accepted by `grade_tools()` but never used, while the return sets `turns=len(results)`, so a multi-turn contract cannot be enforced or represented truthfully.
2. Transient provider failures are written into `trace` as ordinary failed task outcomes (`passed=False`) instead of being distinguished from model/tool errors, contaminating scores and hide rollout outages behind negative grades.
3. `t["id"]` and `t["prompt"]` are used unguarded inside/outside the `try`, so malformed task data raises `KeyError` and aborts the whole benchmark rather than recording just that task failure.
4. Non-transient exceptions raised during extraction/evaluation propagate past the loop, abandoning remaining tasks instead of preserving completed results with an error entry.
5. An absent `expected` value is silently treated as “no tool must be called”; callers should not confuse omitted expectations with explicit no-call tests unless the schema requires `expected: null`.
6. `C.extract_tool_call(resp)` result is assumed to be dict-like, and `exp` is assumed to be dict-like except for its key access before validation; an unexpected shape crashes evaluation outside the recovery path.
7. Trace records keep raw arguments and expected outputs rendered through f-strings; sensitive prompts or credentials included in those structures can leak beyond the final 160-char truncation without redaction/allowlisting.
8. The response returns `by_lang={}` even though language breakdown appears intended by name/contract, so consumers see a successful shape with missing per-language scoring instead of an honest empty contract or actual grouping.
9. When taken verbatim from this excerpt, `_code_system_prompt()` ends mid-return and leaves literal `{l}` / `{e}` placeholders unfilled (and incomplete parentheses), so it cannot produce the composed instruction text.
10. If any task has zero completed results due to configuration errors, score becomes exactly 0.0 and `passed=False` rather than surfacing “empty suite” as invalid, masking misconfigured runs behind normal failure accounting.
