1. `.track .zero` — hardcoding `left:50%` assumes a symmetric negative/positive domain, so the zero baseline and all gauge geometry are misleading whenever the actual range is asymmetric.
2. `.bar` / `.bar.pos` — the base `.bar` has no background and only `.bar.pos` sets one, leaving non-positive/negative bars unstyled and effectively invisible.
3. `.ticks` — dividing the axis into five equal columns assumes evenly spaced tick labels across min/max; it breaks unless every report uses that same linear, symmetric tick contract.
4. `.row` / `.delta` — the fixed 56px right column plus `min-width:56px` does not accommodate longer signed magnitudes, so valid numeric deltas can overflow or clip instead of wrapping, truncating, or reducing size.
