1. Import zone (`#drop`) — it advertises markdown import while `accept=".md,.markdown,.txt"` also opens plain text files with no contract or validation for what content is valid.
2. Search status element (`#search-info`) — its screen-reader behavior is not established by the generated HTML alone; updates are made to a visually hidden region without evidence that assistive technologies receive them as an announced state change.
3. Static hero CTA (`href="proves.html"`) — it depends on one same-directory HTML target being present in every deployment and uses no generated/path-aware reference to avoid broken links when pages are relocated or nested.
4. Dialog overlay (`role="dialog" aria-modal="true"`) — activation and dismissal semantics depend entirely on omitted JavaScript rather than this visible markup; there is no fallback ensuring keyboard users can close, focus, or exit the modal.

Group rendering (`<div id="groups">{''.join(group_sections)}</div>`) — any group section content reaches the static page unescaped, so correctness relies on outside code consistently sanitizing title/body material before interpolation; otherwise dynamic markdown or metadata can be injected into the final HTML.
